# 12 V DC Power Calculators

Calculators for car, 4x4, caravan and camper electrics: voltage drop (with how warm the cable gets), cable size, fuse size, watts and amps, inverter draw, battery runtime, a daily power budget, an EcoFlow power station chooser, solar sizing, and battery percentage from voltage. Each calculator has a live drawing that explains it.

Plain HTML, CSS and JavaScript in one page: open `index.html` in a browser. Nothing you enter leaves your browser. The numbers are estimates, so check the cable maker's data sheet and ask a qualified auto-electrician about big installs.

Live at https://dc-power.psyphin.co.za/
